# رنگ‌نما — پیش‌نمای هوشمند رنگ ساختمانی

مشتری عکس اتاق/نمای ساختمان را می‌دهد (یا یک فضای نمونه را انتخاب می‌کند)، هوش مصنوعی
دیوارها را تشخیص می‌دهد و آن‌ها را با رنگ انتخابی از کاتالوگ بازرنگ‌آمیزی می‌کند —
با حفظ نور، سایه و بافت واقعی عکس.

> ابزار داخلی برای واحد فروش، نمایندگان و مشتریان. همه‌ی مدل‌ها متن‌باز و **لوکال**
> اجرا می‌شوند؛ هزینه‌ی API صفر است.

## امکانات

| بخش | توضیح |
|---|---|
| تشخیص هوشمند دیوار | مدل Mask2Former (ADE20K، لایسنس Apache-2.0) |
| رنگ‌آمیزی واقع‌گرایانه | فضای رنگی Lab + حفظ بافت/کنتراست + guided-filter روی لبه‌ها + ترکیب در فضای خطی نور |
| اصلاح دستی | قلم «افزودن/پاک‌کردن دیوار» روی نواحی‌ای که مدل اشتباه کرده |
| چند دیوار، چند رنگ | هر دیوار را جدا رنگ کن |
| فضاهای نمونه | پذیرایی، اتاق خواب، آشپزخانه (SVG) برای کسی که نمی‌خواهد عکس بدهد — نتیجه‌ی آنی و دقیق |
| حالت نور محیط | طبیعی / گرم / سرد / شب |
| مقایسه‌ی قبل و بعد | اسلایدر روی تصویر |
| تمام‌صفحه | نمایش تمام‌صفحه‌ی تصویر |
| ماشین‌حساب رنگ | ابعاد اتاق → لیتر، تعداد حلب، برآورد هزینه |
| کارت پیشنهاد رنگ | تصویر قابل‌اشتراک شامل نتیجه + کدهای رنگ + برآورد |
| فرم مشاوره (لید فروش) | ثبت شماره‌ی مشتری برای پیگیری |
| داشبورد مدیریت (`/admin`) | تعداد استفاده، پرطرفدارترین رنگ‌ها، روند ۱۴ روزه، لیدها |

## اجرا روی سیستم (بدون Docker)

پیش‌نیاز: Python 3.10+

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run.ps1
```

مرورگر: <http://localhost:8000>  ·  داشبورد: <http://localhost:8000/admin>

> اولین اجرا مدل (~۴۳۰ مگابایت) را دانلود می‌کند؛ بعد از آن آفلاین کار می‌کند.
> CPU: هر عکس ۵–۸ ثانیه. GPU: زیر ۱ ثانیه. فضاهای نمونه همیشه آنی هستند.
> برای CPU ضعیف، مدل سبک‌تر:  `$env:SEG_MODEL_ID="nvidia/segformer-b0-finetuned-ade-512-512"`

## اجرا با Docker (همان چیزی که روی سرور شرکت می‌رود)

```bash
docker compose up --build
```

مدل داخل ایمیج بسته می‌شود؛ روی سرورِ بدون اینترنت هم بالا می‌آید.

## API

| مسیر | کار |
|---|---|
| `GET /api/catalog` | کاتالوگ رنگ: خانواده‌ها، مجموعه‌ها، محصولات، رنگ‌ها |
| `POST /api/mask` | تشخیص دیوار → PNG (سفید = دیوار)؛ با `x,y` فقط همان دیوار |
| `POST /api/visualize` | عکس + کد رنگ (+ ماسک، نور، شدت) → JPEG |
| `POST /api/visualize-multi` | چند دیوار با رنگ‌های مختلف (JSON) |
| `POST /api/estimate` | ابعاد اتاق → مقدار رنگ |
| `POST /api/lead` | ثبت درخواست مشاوره |
| `GET /api/stats` | آمار داشبورد |

## لایسنس مدل‌ها

- **پیش‌فرض** `facebook/mask2former-swin-base-ade-semantic` — کد و وزن‌ها Apache-2.0، مناسب استفاده‌ی تجاری.
- گزینه‌ی سریع `nvidia/segformer-*` — برای استفاده‌ی تجاری محدودیت دارد؛ فقط برای تست محلی.

## داده‌های نمونه

`backend/data/palette.json` — کدها با الگوی کاتالوگ ساخته شده‌اند و **مقادیر HEX تقریبی‌اند**.
پیش از انتشار، با داده‌ی اسپکتروفتومترِ واحد R&D جایگزین شوند.

```
  admin.html  admin.js                داشبورد

```
